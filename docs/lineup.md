# 劇団四季の上演予定

`/lineup`。提供された `shiki-lineup-handoff.zip` の試作を、既存のNext.js / THEATRE NOTESに移植したページです。旧スケジュール機能や削除対象のDBテーブルは再利用しません。DB変更・APIキー・自動取得・定期実行は不要です。

## 表示と操作

- 縦が作品・公演地、横が月の年間表。公演リストにも切り替え可能。
- 地域、月、作品・都市・劇場名、お気に入りだけの表示を組み合わせて絞り込み。
- スマートフォンでは表の領域だけ横スクロールし、左の作品名を固定。注目公演も横スクロール可能。
- 公演名や月の帯を選ぶと詳細が開く。Escape / 閉じるボタン / 背景クリックで閉じる。
- 公式ラインアップへのリンクを設置。

## データと更新

`data/shiki-lineup.json` が唯一のデータ源です。元データ確認日2026-10-21、表示期間2026-10〜2027-10、提供データ19公演。公式サイトの注記（横浜ノートルダム、東京ウィキッド、ジャック、京都ロボット、大阪アナ雪）は組み込み時に照合しました。表画像から読み取った各帯の全範囲については提供資料のスナップショットを維持しています。公式の変更を自動追跡する仕組みはありません。

- `checked`: 元データの確認日。再ビルド・ページ閲覧だけでは更新しない。
- `source`: 出典URL。
- `displayFrom` / `displayThrough`: 保存データの収録範囲。現在は2026-10〜2027-10。画面の開始月とは独立。過去データを消して今月に合わせない。
- `featuredIds`: 注目公演のID。カードの名前・期間・劇場は公演データから取得。
- `performances[].id`: 公演単位の安定ID。お気に入りのキーなので、タイトルの表記修正で変えない。
- `from` / `through`: 月の帯を描く範囲。開幕日・千秋楽日ではない。日付に変換してDB登録しない。
- `start` / `end`: 判明している厳密な日付のみ。`null`は推測で埋めない。既存公演の`start: null`は開幕日が元資料に載っていないことを含む。
- `monthly`: 月単位のみの発表。帯を斜線にし「日付未発表」を表示。
- `open`: 終演時期未発表。`through`は表示の末尾であり千秋楽ではない。`end`はnullのまま。
- `end`がnullの既存公演も、帯の末尾に「…」を表示。空欄を休演と断定しない。

全国公演は開催地別の日程を収録せず、「こころの劇場」など一般販売対象外の公演も含み得ます。詳細・最新の販売状況は公式で確認する案内を表示します。

更新時は公式の表と注記を確認し、このJSONを編集して確認日と収録範囲を更新します。過去の公演・帯・安定IDは削除せず保持し、新しい期間を追加します。開幕・終演が未発表の帯を新しい表示窓に合わせて勝手に延長しません。同じ公演の発表内容が変わった場合は訂正し、変更前の版はGit履歴に残ります。このページは各時点の版を比較する履歴機能や上演実績の証明ではありません。今回はデータ自動更新を実装しません。

## お気に入り

公演単位で、このサイトのlocalStorage `shiki-favorites` に保存。アカウントとの紐付け・端末間同期はありません。試作と別オリジンのため試作側の登録は自動移行されません。JSON不正値は無視し、保存拒否時も画面内で操作できるようにしつつ永続化できない旨を表示します。

## 検証

`npm run test:lineup` で不明日付を補完しないこと、開放期間の末尾を終演日にしないこと、月範囲、保存値の扱いを確認できます。

ブラウザでは4つの幅、表の横スクロールと作品列の固定、複合絞り込み、表示切替、詳細、保存・再読み込み・解除、ストレージ破損・利用不可を確認します。

## Gmailへの変更通知

公式が変わったときに自分宛てに知らせる設定ページ `/lineup/notifications` を追加しました。Google側で初回設定が必要です。画像内容と注記を監視する機能で、公演データの自動反映はしません。設定手順・未実施のGoogle上の動作確認は [lineup-notifications.md](lineup-notifications.md) を参照してください。

## 月替わりと過去表示

初期表示「今月から先」は日本時間の今月から13か月。ブラウザで現在月を取得し、開いたままでも毎分および画面復帰時に確認します。静的生成時の月に固定せず、サーバー描画では確認月を使いhydration後に現在月へ合わせます。

「過去1年」は先月までの12か月。「収録期間すべて」は保存済みの全期間。開始月入力・前後1か月ボタンで同じ年間表／公演リストを移動できます。期間を変えると月フィルターのみ解除し、地域・検索・お気に入りは保持。手動で開始月を選んだ間はその月を固定し、期間ボタンを押すと自動の開始月に戻ります。表の地域・月・検索・お気に入りはすべて期間内の公演が対象です。今月の列は緑色。注目公演も保存範囲が過去になったら非表示です。

収録前・収録後は未収録の案内を表示。過去の表も保存された予定であり、実際の上演実績・個人の観劇記録ではありません。2026年10月より前は未収録で、遡ったデータを生成しません。予定が過去になってもJSONを削除しなければ同じ表から参照できます。
